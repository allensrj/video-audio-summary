# 报告写作与复核

先用几句话概括主题、结论及适用范围。随后按真实议题组织，不机械地每隔几分钟写一段。

- 办公会议：讨论背景、不同方案、明确决策、待办。负责人和日期没有明确说出时写“未明确”，不能自行安排。
- 课程：概念定义、论证或推导、例题、易错点、复习要点。讲者没给出的知识扩展需明确标为补充，不能混为课堂原话。
- 软件演示：目的、前提、操作顺序、界面结果、注意事项。不能仅凭截图推断不可见点击或输入。

每一条关键结论附证据 ID 和原始时间。图片配标题与具体说明，说明它补充了什么；公式、图表和数字看不清则写明限制。画面和语言冲突时同时陈述，不能悄悄选一方。

长内容按阅读索引逐包记录要点，再合并主题；保留每包覆盖情况。原始资料仍为最终事实来源。ASR 切块前后、长静音后的首句、数字/人名、重复句、会议决策变化是重点复核位置。

看过全部采样图不等于看过所有视频帧。报告应标出采样间隔、补帧范围、没有检查的模态、空转写或失败区间。听不清的内容不补造。

交付前：抽查所有关键结论引用，查看实际使用的原图，核对来源文件与时长，确认图像相对路径能打开，移除模板占位符。所有数字、任务指派和公式若不能验证则标记待核实。
